# English Localization (react-i18next) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make WinAdmin English-first: SPA via `react-i18next` (default `en`, `ru` key mirror), backend/CLI/docs via direct English string replacement.

**Architecture:** Frontend loads `i18next` before render; UI copy lives in `src/frontend/src/i18n/locales/{en,ru}/{common,pages,logs}.json`. Ant Design locale tracks i18n language. Backend, CLI, and markdown/scripts get English literals in place. OS match aliases like `СИСТЕМА` stay. Historical `docs/superpowers/**` untouched.

**Tech Stack:** React 19 + TypeScript + Vite + Ant Design 6 + i18next/react-i18next; ASP.NET Core (C#); PowerShell release scripts; Markdown docs.

**Spec:** `docs/superpowers/specs/2026-07-12-english-i18n-design.md`

## Global Constraints

- Default + fallback language: `en`. No language switcher UI in v1.
- Ship `ru/` JSON as a key-compatible mirror of `en/`.
- Do not rename routes, scopes (`system.read`), audit action codes, or DB schema.
- Keep OS match aliases such as `"СИСТЕМА"` next to `"SYSTEM"` in event-log helpers/tests.
- Do not edit `docs/superpowers/specs/**` or `plans/**` except adding this plan.
- Do not hand-edit `artifacts/` or compiled `wwwroot` bundles; rebuild frontend when needed.
- Ship frontend + backend message changes in the same change set (avoid EN UI + RU API).
- Product name stays **WinAdmin**; use natural American English.

- [ ] **Step 2: Write failing key-parity script**

Create `src/frontend/scripts/check-i18n-keys.mjs`:

```js
import fs from 'node:fs'
import path from 'node:path'
import { fileURLToPath } from 'node:url'

const root = path.join(path.dirname(fileURLToPath(import.meta.url)), '..', 'src', 'i18n', 'locales')
const langs = ['en', 'ru']
const namespaces = ['common', 'pages', 'logs']

function flatten(obj, prefix = '') {
  const out = []
  for (const [k, v] of Object.entries(obj)) {
    const key = prefix ? `${prefix}.${k}` : k
    if (v && typeof v === 'object') out.push(...flatten(v, key))
    else out.push(key)
  }
  return out.sort()
}

function load(lang, ns) {
  const p = path.join(root, lang, `${ns}.json`)
  if (!fs.existsSync(p)) throw new Error(`Missing locale file: ${p}`)
  return JSON.parse(fs.readFileSync(p, 'utf8'))
}

let failed = false
for (const ns of namespaces) {
  const enKeys = flatten(load('en', ns))
  const ruKeys = flatten(load('ru', ns))
  const missingInRu = enKeys.filter((k) => !ruKeys.includes(k))
  const missingInEn = ruKeys.filter((k) => !enKeys.includes(k))
  if (missingInRu.length || missingInEn.length) {
    failed = true
    console.error(`Namespace "${ns}" key mismatch:`)
    if (missingInRu.length) console.error('  missing in ru:', missingInRu.join(', '))
    if (missingInEn.length) console.error('  missing in en:', missingInEn.join(', '))
  }
}
if (failed) process.exit(1)
console.log('i18n key parity OK')
```

```ts
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import enUS from 'antd/locale/en_US'
import ruRU from 'antd/locale/ru_RU'
import type { Locale } from 'antd/es/locale'

import enCommon from './locales/en/common.json'
import enPages from './locales/en/pages.json'
import enLogs from './locales/en/logs.json'
import ruCommon from './locales/ru/common.json'
import ruPages from './locales/ru/pages.json'
import ruLogs from './locales/ru/logs.json'

void i18n.use(initReactI18next).init({
  lng: 'en',
  fallbackLng: 'en',
  defaultNS: 'common',
  ns: ['common', 'pages', 'logs'],
  resources: {
    en: { common: enCommon, pages: enPages, logs: enLogs },
    ru: { common: ruCommon, pages: ruPages, logs: ruLogs },
  },
  interpolation: { escapeValue: false },
})

export function antdLocaleFromLng(lng?: string): Locale {
  return (lng ?? i18n.language)?.startsWith('ru') ? ruRU : enUS
}

export default i18n
```

```tsx
import { StrictMode, useState, useEffect } from 'react'
import { createRoot } from 'react-dom/client'
import { BrowserRouter } from 'react-router-dom'
import { App as AntApp, ConfigProvider } from 'antd'
import { AllCommunityModule, ModuleRegistry } from 'ag-grid-community'
import { useTranslation } from 'react-i18next'
import { WinAdminTheme } from './theme'
import App from './App'
import i18n, { antdLocaleFromLng } from './i18n'
import './index.css'

ModuleRegistry.registerModules([AllCommunityModule])

function Root() {
  const { i18n: i18nInstance } = useTranslation()
  const [antdLocale, setAntdLocale] = useState(() => antdLocaleFromLng(i18n.language))

  useEffect(() => {
    const onLang = (lng: string) => setAntdLocale(antdLocaleFromLng(lng))
    i18nInstance.on('languageChanged', onLang)
    return () => { i18nInstance.off('languageChanged', onLang) }
  }, [i18nInstance])

  return (
    <ConfigProvider theme={WinAdminTheme} locale={antdLocale}>
      <AntApp>
        <BrowserRouter>
          <App />
        </BrowserRouter>
      </AntApp>
    </ConfigProvider>
  )
}

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <Root />
  </StrictMode>,
)
```
